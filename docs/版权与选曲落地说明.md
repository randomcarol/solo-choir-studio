## 《彩虹》需要取得什么

《彩虹》是金承志在世期间创作的现代作品，不能因为网上能听到、能下载观众录像或能买到一份曲谱，就视为获得产品使用权。建议先通过上海彩虹室内合唱团官网的“商务合作 / 曲谱咨询”联系权利团队，同时在中国音乐著作权协会的“管理作品检索”中查询作品与代理权范围。

音著协当前公布的新媒体和复制权许可业务部联系方式为 `mulb@mcsc.com.cn`，总机 `010-65232656`；上海地方许可团队电话为 `021-60193272`。询问时应明确这是交互式 Web 声乐练习和用户录音功能，而不是普通在线播放。

向权利人发送的最小申请范围：

1. 产品：手机 Web 原型“和声里”，让用户练习并录制高、中、低三个声部。
2. 素材：请求权利人提供或批准制作 MIDI / MusicXML；不需要原唱母带时明确排除母带。
3. 权利：词曲复制、数字化、为三声部练习进行的改编/移调、通过网络向限定测试用户提供，以及用户演唱录音所需的使用范围。
4. 限制：封闭测试、限定账号和人数、限定三个月、不公开搜索、不提供带歌名分享、不包含歌词、录音默认仅本地保存。
5. 地域与终端：中国大陆、Web 浏览器；如以后做 App 另行补充。
6. 交付：旋律、节拍、段落、调性、三个声部的 MIDI/MusicXML；如需要真人导唱，再单列录音制作者与表演者授权。
7. 合同：要求授权方说明其有权授权的权利种类、期限、地域、是否允许转授权以及署名方式。

可直接发送的询价文案：

> 您好，我们正在开发手机 Web 原型“和声里”，希望申请金承志创作、上海彩虹室内合唱团演唱的《彩虹》用于封闭产品测试。测试功能包括：按高/中/低声部显示音高轨道、以合成音或授权分轨导唱、用户在浏览器内录制自己的三个声部并仅供本人回放/下载。希望获得或获准制作不含歌词的 MIDI/MusicXML，并进行必要的三声部适配与移调。首期拟限定中国大陆、Web 端、3 个月、100 个测试账号，不公开检索或分享，不使用原唱母带。烦请告知贵方可授权的权利范围、素材交付方式、署名要求和报价；如有权利需由其他主体或音著协另行许可，也请协助指出。

## 网易云音乐与全民 K 歌的公开做法

网易云音乐在公开年报中说明，其大量音乐内容来自与中国及海外音乐出版商、唱片公司的许可协议，同时经营原创音乐并在获得范围内对部分内容进行转授权。也就是说，它不是简单依靠“网上已有”或用户上传。

腾讯音乐的公开年报说明，全民 K 歌（WeSing）使用其卡拉 OK 曲库，并向唱片公司、音乐版权方及个人艺人签订许可或委托创作协议、支付版税。2025 年披露的音著协协议用于补齐现有唱片公司/版权方合同尚未覆盖的底层词曲网络传播许可。用户演唱形成 UGC，但 UGC 并不替代平台对底层歌曲的许可。

平台型产品常见的四层来源是：

- 唱片公司、音乐出版商和词曲权利人的曲库许可；
- 音著协等集体管理组织覆盖其管理的词曲权利；
- 自制、委约创作或直接签约独立音乐人；
- UGC 协议、权利声明、投诉下架与重复侵权管理。

## 只允许用户上传、本地运行是否可以

可以作为低风险 Demo 架构，但不是自动免责。当前实现采用：

- 用户必须主动选择本机 MIDI 或未压缩 MusicXML，页面不会扫描设备或抓取流媒体文件；
- 用户勾选“拥有测试和使用权”；
- 文件只在浏览器内解析，不上传、不保存到服务器；
- 默认没有公开分享或作品库；
- App 自己仍只提供公版旋律，不提供受保护歌曲的谱或伴奏。

中国著作权法允许为个人学习、研究或欣赏使用已经发表的作品，但同时要求不得影响作品正常使用或不合理损害权利人利益。产品一旦面向多名用户提供、诱导上传、在云端处理、保存、分享或由平台提供受保护的伴奏/旋律，就不应只依赖“个人使用”例外。

如果以后开放云端上传，需要至少增加权利保证条款、投诉与下架机制、重复侵权处理、内容留存周期、隐私同意，并评估是否需要曲库许可或音频指纹识别。

## 学校和民间合唱团是否要授权

- 封闭排练通常不等于向公众传播，但购买一份曲谱不当然允许大量复印或制作新编曲。
- 公开演出原则上由演出组织者取得许可并支付报酬。
- 不向公众收费、不向表演者支付报酬且不以营利为目的的免费表演，可能落入著作权法第二十四条的合理使用情形，但仍需署名、不得影响正常使用或不合理损害权利人利益。
- 录制演出、直播、上传视频、发行录音或使用受保护的伴奏，会触发与现场演出不同的复制、信息网络传播以及表演/录音录像制品相关权利，应单独确认。
- 如果合唱团把流行歌重新编成阿卡贝拉，新编曲既可能需要原作品改编许可，新编曲本身也可能产生独立版权。
